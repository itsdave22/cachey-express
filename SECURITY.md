# Security Policy

Security issues should be reported responsibly and privately.

Please do **not** open a public GitHub issue for vulnerabilities that could affect users, applications, credentials, cached data, or infrastructure.

## Reporting a vulnerability

Send a private report through the official Cachey contact channel listed on https://cachey.eu and include:

- A clear description of the issue
- Affected version(s)
- Reproduction steps or proof of concept
- Potential impact
- Any suggested mitigation, if known

We will review valid reports as quickly as possible and coordinate fixes and disclosure where appropriate.

## Supported versions

Until a stable support policy is published, security fixes are prioritized for the latest published version of `@cachey/express`.

Thank you for helping keep Cachey and its users secure.
